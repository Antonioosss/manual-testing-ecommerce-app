# Manual Test Cases

## Overview

This directory contains manual test cases created for the SauceDemo e-commerce web application.

A total of **30 test cases** were designed and executed to verify the main user flows of the application.

The primary test execution was performed using the `standard_user` account.

The test cases include both positive and negative scenarios.

## Test Case Structure

Each test case contains the following information:

- Test Case ID
- Module
- Title
- Preconditions
- Test Steps
- Test Data
- Expected Result
- Priority
- Status
